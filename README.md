# University TechFest Website

A responsive, multi-page university technology festival website developed as Assignment 1 for Advanced Web Technologies (CS554).

## Project Overview

The website will provide information about a university technology festival, its events, schedule, and participant registration.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub

## Pages

- **Home:** Festival introduction, highlights, sponsors, and schedule.
- **Events:** Dynamically rendered events with search and filters.
- **Register:** Participant registration form with JavaScript validation.

## Features

- Responsive mobile-first design
- Light and dark themes
- Dynamic event cards
- Event search, filtering, and sorting
- Saved event schedule
- Registration form validation
